# Core-Sheath-Microfluidic-Flow-Simulation-Using-VOF-in-STAR-CCM-
CFD simulation of core–sheath flow in a herringbone microfluidic channel using the Volume of Fluid (VOF) method, with mesh-independence analysis and investigation of core geometry as a function of sheath-to-core flow-rate ratio.
## Overview

This project investigates the numerical formation of a core–sheath flow inside a three-dimensional herringbone microfluidic channel. The objective is to determine how variations in sheath-to-core flow-rate ratio influence the position, width, and height of the core stream.

A multiphase CFD model was developed in STAR-CCM+ using the Volume of Fluid (VOF) method. The interface between the core and sheath phases was captured using the High Resolution Interface Capturing (HRIC) scheme. A mesh-independence study was performed before conducting a parametric analysis over sheath:core:sheath flow-rate ratios ranging from 1:1:1 to 29.5:1:29.5.

The resulting phase distributions were analyzed at several locations along the channel, and ImageJ was used to quantify changes in the dimensions of the core stream.
